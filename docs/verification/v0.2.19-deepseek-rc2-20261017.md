## DeepSeek 新 API 适配

- 新增可选的 `deepseek` 搜索／提取来源，直接调用 `https://api.deepseek.com/v1/tools/search` 与 `/fetch`。
- 使用 `DEEPSEEK_API_KEY`，Bearer 鉴权，默认关闭；bundle、设置页与 README 均不预启用。
- 搜索发送 `query`、`count`、`need_content: false`，结果数上限为 50；提取以 Markdown 文本返回，报告 HTTP 200。
- 该来源与宿主内置的 `deepseek-search-api` / `deepseek-fetch-api` provider 相互独立；本插件仍注册两个 `aggregated` provider。

本地契约测试覆盖默认地址、鉴权头、搜索上限、响应映射与提取正文。真实 `deepseek` 来源调用未执行：正式 profile 没有 `DEEPSEEK_API_KEY`，本轮没有为此启用或写入新凭证。
